Current research

EXOhSPEC stabilisation

EXOhSPEC stands for Exoplanet High-Resolution Spectrograph. My current research builds and tests a closed-loop feedback control pipeline to stabilise the instrument's optical path against environmental drift, using off-the-shelf hardware components.

Current focus

Hybrid TEC–AO closed-loop pipeline

The control system combines a TEC (thermoelectric controller) as the primary coarse regulator with an AO (adaptive optics) tip-tilt unit for fine sub-pixel correction. IDS3010 interferometric OPL data and environmental sensor readings (temperature, pressure, humidity) feed into a Python-based controller running continuous feedback loops.

  • TEC handles coarse thermal correction (>~1 px drift)
  • AO provides fine trim correction in the sub-pixel regime
  • Interferometric OPL monitoring tracks optical path drift
  • Rolling OLS model used for feedforward temperature estimation
  • V4 run achieved ~0.50 px RMS dY — ~23% improvement over April baseline
