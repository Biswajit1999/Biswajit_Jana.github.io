# Security Policy

## Reporting A Vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting form:

<https://github.com/Biswajit1999/Biswajit_Jana.github.io/security/advisories/new>

Include the affected page or asset, a concise description of the concern, reproduction steps where applicable, and any suggested mitigation. Reports concerning broken links, wording, or ordinary display bugs should instead use the public issue forms.

## Scope

This repository publishes a static GitHub Pages portfolio website. Relevant security reports may include exposed secrets, unsafe client-side behavior, unexpected third-party script behavior, or a vulnerability introduced in an interactive browser tool.

No sensitive information should be included in a public report.
