# Support

This repository publishes Biswajit Jana's academic portfolio, scientific writing, and interactive learning tools.

- For a broken page or interactive feature, open a **Website problem** issue.
- For a scientific wording, citation, or attribution correction, open a **Content correction** issue.
- For a private security concern, use the private vulnerability reporting link in [SECURITY.md](SECURITY.md).
- For research or professional contact, use the contact links on the [published website](https://biswajit1999.github.io/Biswajit_Jana.github.io/).

Please do not use issue tracking for personal data, confidential correspondence, or requests to reproduce copyrighted site material.
