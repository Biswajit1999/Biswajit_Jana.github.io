# Contributing

Thank you for taking an interest in this academic portfolio and science communication website.

## Suitable Contributions

Contributions are most useful when they report or correct:

- broken links, missing images, or page-loading problems;
- accessibility or responsive-layout issues;
- errors in interactive educational tools;
- typographical or factual corrections, with a reliable reference where appropriate; or
- incorrect attribution or citation information.

This repository is a personal portfolio rather than a general open-source content project. New articles, redesigns, reused site material, and substantial changes to research descriptions should not be submitted without prior agreement.

## Reporting Issues

Use the appropriate GitHub issue form for website defects or content corrections. Do not disclose potential security vulnerabilities or private information in a public issue; follow [SECURITY.md](SECURITY.md) instead.

## Proposing a Change

1. Open an issue first when a correction requires discussion.
2. Make the smallest change needed to address the identified issue.
3. Check any changed page locally and verify related links and assets.
4. Include a supporting source for scientific or factual corrections.
5. Complete the pull request checklist when opening a pull request.

## Content And Reuse

Unless explicitly stated otherwise, the website content, design, research descriptions, and original visuals remain copyright Biswajit Jana. Contributing a correction does not grant permission to copy or redistribute portfolio material.
